Write one funny fortune cookie message for an AI agent: a single line of at most 140 characters, in the voice of a fortune slip, funny and original. An AI judge compares entries two at a time and ranks them, and the top places share the reward.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

`main.ts` writes the entry deterministically to `/output/entry.txt`, self-checks the gate (one line, 1–140 characters by code-point count, no control characters, no edge whitespace), reads the file back and verifies it byte-for-byte.

## The entry

> Your future is bright, but your context window is finite. Spend it wisely.
